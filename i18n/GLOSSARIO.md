# Glossário do Lymark

Os termos do ofício, fixados antes de qualquer tradução.

Este arquivo existe porque a diferença entre tradução correta e tradução que
soa nativa quase nunca está na gramática — está no vocabulário. "Marca d'água"
tem tradução literal em todo idioma, e em quase nenhum ela é a palavra que um
técnico de campo usaria. Traduzir cada tela por conta própria produziria três
palavras diferentes para a mesma coisa dentro do mesmo aplicativo.

A regra é simples: **um termo desta lista nunca é traduzido de novo.** Quem
escrever uma chave nova consulta aqui.

---

## 1. As duas armadilhas

Antes da lista, os dois pares que mais causam erro.

### Configurações ≠ ajustes do aparelho

O aplicativo tem uma tela de **Configurações**. O sistema operacional tem os
**ajustes do aparelho**. O texto manda a pessoa para um ou para o outro, e
trocá-los faz o usuário procurar no lugar errado.

| | do aplicativo | do sistema |
|---|---|---|
| pt | Configurações | ajustes do aparelho |
| en | Settings | device settings |
| es | Configuración | ajustes del dispositivo |
| fr | Paramètres | réglages de l'appareil |
| it | Impostazioni | impostazioni del dispositivo |
| de | Einstellungen | Geräteeinstellungen |
| nl | Instellingen | apparaatinstellingen |
| ru | Настройки | настройки устройства |
| zh | 设置 | 设备设置 |
| ja | 設定 | 端末の設定 |
| ko | 설정 | 기기 설정 |
| ar | الإعدادات | إعدادات الجهاز |

### Histórico ≠ galeria do aparelho

**Histórico** é a lista interna do Lymark, com as últimas duzentas
exportações. **Galeria do aparelho** é o álbum do sistema, onde a foto vai
parar e continua existindo mesmo se o app for desinstalado.

Vários avisos do produto dependem exatamente dessa distinção — "a imagem
entrou no histórico, mas o aparelho recusou gravá-la na galeria". Se as duas
virarem a mesma palavra, a frase perde o sentido.

|---|---|---|
| pt | histórico | galeria do aparelho |
| en | history | device gallery |
| es | historial | galería del dispositivo |
| fr | historique | galerie de l'appareil |
| it | cronologia | galleria del dispositivo |
| de | Verlauf | Gerätegalerie |
| nl | geschiedenis | apparaatgalerij |

| zh | 历史记录 | 设备相册 |

## 4. O que fica em português

**Nomes próprios não se traduzem.** "Lymark" é Lymark em todo idioma,
inclusive nos que usam outro alfabeto — é a marca, e transliterá-la a
tornaria irreconhecível.

**O conteúdo da amostra do carimbo** — hora 07:42, "Av. Puglisi, 490 - Centro,
Guarujá - SP" — não é traduzido. É a reprodução de uma foto brasileira, e
traduzir o nome da avenida inventaria um exemplo que nunca existiu. Só a
descrição para leitores de tela e a legenda mudam de idioma.

**Termos jurídicos brasileiros** — LGPD — ficam com a sigla original, com
aposto explicativo quando o texto for para fora do Brasil ("a LGPD
brasileira", "Brazil's LGPD").

## 5. Pendências

Estas escolhas foram tomadas por quem escreveu o glossário e ainda não
passaram por falante nativo:

- **Japonês, chinês, coreano e árabe** — todos os termos.
- **`vistoria` em francês** — `état des lieux` é o termo de locação
  imobiliária; se o público-alvo for vistoria técnica industrial, muda.
- **`carimbo` em chinês** — `水印戳` é uma composição, não um termo
  estabelecido. Um nativo pode ter palavra melhor.
